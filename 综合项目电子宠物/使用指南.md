# ESP32-C3 电子宠物 — 使用指南

## 一、系统概述

基于 ESP32-C3 的桌面电子宠物，通过 OLED 屏显示状态信息、三色墨水屏显示宠物外观，16 键触摸键盘操控，配备多种环境传感器。支持 WiFi 连接和手机 Web 作弊控制台。

### 硬件组成

| 模块 | 型号 | 功能 |
|------|------|------|
| 主控 | ESP32-C3 | 系统核心 |
| OLED 屏 | SSD1315 128x64 | 状态/菜单显示 |
| 墨水屏 | SSD1680 122x250 三色 | 宠物外观图片 |
| 触摸键盘 | TTP229 16键 | 用户输入 |
| 实时时钟 | DS1307 + AT24C32D | 时间/EEPROM存档 |
| 温湿度 | DHT11 | 环境温湿度采集 |
| 光照 | BH1750 | 环境光照检测 |
| 加速度计 | MPU6050 | 摇晃检测 |
| 蜂鸣器 | 无源蜂鸣器 | 按键音效/提示音 |

### 宠物三大属性

| 属性 | 范围 | 初始值 | 说明 |
|------|------|--------|------|
| HP (体力) | 0 ~ 100 | 80 | 降到 0 宠物死亡 |
| Mood (心情) | 0 ~ 100 | 80 | 影响打工收入和外观 |
| Coins (金币) | 0 ~ 99999 | 100 | 用于购买食物 |

---

## 二、按键功能

16 个触摸按键，每个按键按下时会发出对应音阶的提示音 (C4 ~ D6)。

| 键号 | 标记 | 功能 |
|------|------|------|
| 0 | Feed | 进入喂食菜单 |
| 1 | Play | 进入互动/逗乐菜单 |
| 2 | Work | 开始打工 |
| 3 | Fight | 开始战斗 |
| 4 | Up | 菜单上移 |
| 5 | Down | 菜单下移 |
| 6 | OK | 菜单确认 |
| 7 | Back | 返回主界面 |
| 8 | Num 8 | 逗乐游戏输入 "1" |
| 9 | Num 9 | 逗乐游戏输入 "2" |
| 10 | Num A | 逗乐游戏输入 "3" |
| 11 | Num B | 逗乐游戏输入 "4" |
| 12 | Pet C | 抚摸宠物 |
| 13 | Pet D | 抚摸宠物 |
| 14 | NTP | WiFi 校时 (同步 NTP → RTC) |
| 15 | Save | 手动存档 |

## 三、主界面 (STATE_MAIN)

OLED 显示内容：

```
PET                 HH:MM     ← 标题 + 当前时间
─────────────────────────
HP [████████░░] 75            ← 体力进度条
MD [██████░░░░] 60            ← 心情进度条
Coin: 1500                    ← 金币数
T:25C H:60% L:300             ← 温度/湿度/光照
─────────────────────────
0Fd 1Pl 2Wk 3Ft F:Sv         ← 操作提示
```

## 四、活动系统与属性变化规则

### 4.1 喂食 (键 0 → 菜单选择 → 键 6 确认)

用金币购买食物恢复体力。HP 已满时无法喂食。

| 食物 | 价格 | HP | Mood | 说明 |
|------|------|-----|------|------|
| Bread (面包) | 5G | +20 | 0 | 便宜实用 |
| Steak (牛排) | 15G | +40 | +5 | 高性价比 |
| Cake (蛋糕) | 10G | +10 | +15 | 主加心情 |
| Potion (药水) | 20G | +60 | -10 | 大量回血但降心情 |

### 4.2 抚摸 (键 C 或 D)

在主界面直接按键 C 或 D 触发。

| 属性 | 变化 |
|------|------|
| Mood | +15 |
| HP | -3 |
| 冷却 | 30 秒 |

### 4.3 摇晃 (物理晃动设备)

MPU6050 检测到加速度剧变时自动触发。

| 属性 | 变化 |
|------|------|
| Mood | +20 |
| HP | -5 |
| 冷却 | 60 秒 |

### 4.4 逗乐小游戏 (键 1 → 键 6 开始)

屏幕显示 4 位数字序列 (1~4)，玩家用键 8/9/A/B 依次输入，10 秒内完成。

| 结果 | Mood | HP | 冷却 |
|------|------|----|------|
| 成功 | +35 | -5 | 2 分钟 |
| 失败/超时 | +5 | -5 | 2 分钟 |

### 4.5 打工 (键 2)

需要 HP >= 15 才能开始，持续 30 秒后自动结算。

| 属性 | 变化 |
|------|------|
| HP | -15 |
| Mood | -10 |
| 金币 | +10 ~ +30 (取决于心情) |

**金币收入规则：**

| 心情状态 | 条件 | 基础收入 (20G) |
|----------|------|----------------|
| 心情好 | Mood > 70 | x1.5 = 30G |
| 心情正常 | 30 <= Mood <= 70 | x1.0 = 20G |
| 心情差 | Mood < 30 | x0.5 = 10G |

### 4.6 战斗 (键 3)

需要 HP >= 20 才能开始，2 秒动画后自动结算。

**胜率计算：** 胜率 = 40% + HP/2 (例如 HP=80 时胜率 80%)

| 结果 | 条件 | 金币 | HP | Mood |
|------|------|------|----|------|
| 大胜 | 胜利 且 HP>50 且 10%概率 | +100 | -5 | +20 |
| 普通胜利 | 胜率判定成功 | +40~60 (随机) | -10 | 不变 |
| 失败 | 胜率判定失败 | +10 | -30 | 不变 |

### 4.7 手动存档 (键 F)

立即将当前状态写入 EEPROM (A/B 双槽 + XOR 校验)。

## 五、自然衰减规则

每 60 秒触发一次衰减检查，属性自动下降：

### 5.1 HP 衰减

| 速率 |
|------|
| 每分钟 -1 |

### 5.2 Mood 衰减

| 条件 | 速率 |
|------|------|
| 正常温度 | 每 2 分钟 -1 |
| 温度异常 | 每 2 分钟 -2 |

**温度异常判定：** 温度 > 35°C 或 温度 < 10°C

### 5.3 离线衰减

关机/断电期间，重新开机后根据离线时长补算衰减（上限 24 小时）：
- HP：离线分钟数 x 1
- Mood：离线分钟数 / 2

### 5.4 死亡与复活

- **死亡条件：** HP 降至 0
- **复活方式：** 死亡界面按任意键复活（HP=50, Mood=50），或通过 Web 作弊台复活

---

## 六、宠物外观规则

墨水屏根据属性自动切换宠物图片（优先级从高到低）：

| 优先级 | 条件 | 外观 |
|--------|------|------|
| 1 | 宠物死亡 | DEAD (死亡) |
| 2 | 光照 < 50 lux | SLEEP (睡觉) |
| 3 | HP <= 30 | HUNGRY (饥饿) |
| 4 | Mood <= 30 | SAD (难过) |
| 5 | HP > 70 且 Mood > 70 | HAPPY (开心) |
| 6 | 其他 | NORMAL (普通) |

---

## 七、存档系统

- **自动存档：** 每 90 秒自动保存一次
- **手动存档：** 按键 F (键 15)
- **存档位置：** EEPROM (AT24C32D)，A/B 双槽冗余，XOR 校验
- **活动存档：** 喂食、逗乐、打工、战斗结算后自动存档

---

## 八、Web 作弊控制台

### 连接方式

1. 设备开机后自动连接预设 WiFi
2. 串口输出设备 IP 地址
3. 手机连接同一 WiFi，浏览器访问 `http://<设备IP>`

### 功能按钮

| 按钮 | 效果 |
|------|------|
| +500 Coins | 金币 +500 |
| +1000 Coins | 金币 +1000 |
| HP Max | HP 设为 100 |
| Mood Max | Mood 设为 100 |
| All Max | HP=100, Mood=100, 金币+2000 |
| Reset Coins | 金币清零 |
| Revive Pet | 复活宠物 (HP=50, Mood=50) |
| HP 滑块 | 自由设定 HP 值 (0~100) |
| Mood 滑块 | 自由设定 Mood 值 (0~100) |

页面每 2 秒自动刷新属性数据。

---

## 九、NTP 校时 (键 E)

通过 WiFi 连接 NTP 服务器同步时间，并写入 DS1307 RTC。需在 WiFi 已连接状态下使用。
